# stockdesk

เว็บวิเคราะห์หุ้นไทยและสหรัฐฯ: ราคา (ล่าช้าราว 15 นาที), คะแนนเทคนิค + งบ + ข่าว + ปัจจัยมหภาค, จุดซื้อ / TP / SL,
มูลค่าเหมาะสม, ข่าวผูกหุ้นรายตัว, พอร์ตที่ซิงก์ข้ามเครื่องได้ และติดตามผลจริงไปข้างหน้า
เปิดได้ทั้งมือถือและคอม ติดตั้งเป็นแอปบนหน้าจอโฮมได้ · https://auiixb-wq.github.io/stockdesk/

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ (เมนู ช่องค้นหา) ไฟล์ css/js ติดเลขเวอร์ชัน `?v=` ให้เบราว์เซอร์โหลดของใหม่ทันที |
| `app.css` | สไตล์ทั้งหมด (โทนสีใน `:root`, โหมดหุ้นสหรัฐฯ `data-mkt="US"`) |
| `app.js` | การแสดงผลทุกหน้า การโต้ตอบ การโหลดข้อมูล พอร์ต (ตรวจราคาผิดปกติก่อนคิดมูลค่า) และซิงก์พอร์ตแบบเข้ารหัส |
| `core.js` | การคำนวณหลัก (อินดิเคเตอร์ คะแนน แผนซื้อขาย ทดสอบย้อนหลัง มูลค่า) ใช้ร่วมกันทั้งหน้าเว็บและสคริปต์ |
| `sw.js` | แคชหน้าเว็บให้เปิดได้ตอนเน็ตหลุด (ดึงของใหม่ก่อนเสมอ) |
| `symbols.json` | หุ้นในรายการหลัก ดัชนี ปัจจัย และคำค้นข่าวมหภาค |
| `manual.json` | ปัจจัยมหภาคที่ต้องค้นเอง + ข่าวคัดสรร (งานตั้งเวลาของ Claude อัปเดตวันละ 2 ครั้ง) |
| `scripts/update.py` | ตัวสั่งงาน: เรียกแต่ละขั้นตอนตามลำดับ แล้วเขียน `meta.json` |
| `scripts/sd/common.py` | ค่ากลาง: ที่อยู่ไฟล์ เวลา บันทึกปัญหา อ่าน/เขียน JSON รหัสหุ้น |
| `scripts/sd/universe.py` | รายชื่อหุ้นทั้งตลาด (Yahoo) รหัสไม่ซ้ำข้ามตลาด (ซ้ำกันเติม `.US`/`.BK`) ราคาทั้งตลาด (CNBC/Yahoo) ราคาย้อนหลัง 5 ปี |
| `scripts/sd/prices.py` | ราคาล่าสุดและแถบดัชนี |
| `scripts/sd/fin.py` | งบการเงิน (แปลงเป็นสกุลเงินที่หุ้นซื้อขาย) และอัตราส่วนพื้นฐาน |
| `scripts/sd/macro.py` | ปัจจัยมหภาคที่คำนวณจากราคาตลาด |
| `scripts/sd/news.py` | ข่าวจาก ~40 แหล่ง ผูกหุ้น รวมข่าวซ้ำ (เก็บฉบับละเอียดสุด) แปลเป็นไทย |
| `scripts/sd/archive.py` | คลังข้อมูลตลาดสะสม: ภาพราคาทุก ~15 นาที ข่าวทุกข่าว ค่าปัจจัย ส่งเข้า branch `archive` แบบต่อท้าย |
| `scripts/sd/health.py` | ตรวจคุณภาพข้อมูล: กันราคาผิดบริษัท สรุปผลลง `data/health.json` (หน้า "สถานะข้อมูล") |
| `scripts/tests.py` | ทดสอบแบบไม่ต่อเน็ต รันก่อนดึงข้อมูลทุกครั้ง ไม่ผ่านจะไม่เผยแพร่ |
| `scripts/summarize.js` | คำนวณคะแนนทุกหุ้น ความแม่นยำ เกณฑ์แข็งกว่าตลาด |
| `scripts/live.py` | รันต่อเนื่องทั้งวัน: ตลาดเปิด = ราคาทุก ~2 นาที รอบใหญ่ทุก ~30 นาที · ตลาดปิด = ข่าวทุก ~20 นาที |
| `scripts/publish.sh` | เผยแพร่หน้าเว็บ + ข้อมูลไป `gh-pages` และราคาย้อนหลังไป `hist` |
| `research/` | สคริปต์ทดสอบกลยุทธ์ที่ใช้ตัดสินใจ (ดู `research/README.md`) |
| `docs/progress.md` | บันทึกงานและผลทดสอบทั้งหมด |

## ข้อมูล (branch)
- `gh-pages`: หน้าเว็บ + `data/*.json` (summary, uni, quotes, news, calib, rsq, health ฯลฯ)
- `archive`: คลังข้อมูลสะสม `quotes/ news/ macro/` แยกตามวัน (เพิ่มอย่างเดียว ไม่ลบ ใช้วิจัยกลยุทธ์)
- `vault`: พอร์ตที่เข้ารหัสด้วยรหัสผ่านของผู้ใช้ (ถ้าเปิดซิงก์)
- `live`: `quotes.json` และ `meta.json` อัปเดตทุก ~2 นาทีช่วงตลาดเปิด (หน้าเว็บอ่านผ่าน GitHub API)
- `hist`: ราคาย้อนหลัง 5 ปีรายตัว `SYM.json`, งบ `fin/SYM.json`, คะแนนรายวัน `snap/`, คำแนะนำรายวัน `paper/`

## รอบการทำงานอัตโนมัติ
| งาน | เวลา |
|---|---|
| `live.yml` | ทั้งวันทุกวัน (งานละ ~5 ชม. 40 นาที ต่อคิวกัน) |
| `update.yml` | ทุกคืนวันทำการ 04:37 น. (รอบใหญ่: ราคา 5 ปี งบ รายชื่อหุ้น) · สั่งรันเองได้ที่ Actions |
| งานตั้งเวลาของ Claude | 07:13 และ 11:13 น.: อัปเดตปัจจัยใน `manual.json` และตรวจว่างานอัตโนมัติรันจริง |

## ตั้งค่าครั้งแรก
1. Settings → Pages → Source: **Deploy from a branch** → Branch: `gh-pages` / `(root)`
2. Actions → update-data → **Run workflow**
3. เปิด `https://<username>.github.io/<repo>/`

ข้อมูลฟรีจาก Yahoo Finance, CNBC และ Google News ใช้ส่วนตัวได้ ถ้าเผยแพร่เชิงพาณิชย์ต้องซื้อสิทธิ์ข้อมูล · ไม่ใช่คำแนะนำการลงทุน
